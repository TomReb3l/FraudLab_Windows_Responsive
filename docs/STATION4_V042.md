# Station 4 v0.4.2 — Quality Gate + TTS Pronunciation

This patch is a correctness hardening step on top of v0.4.1.

It addresses three observed issues:
1. malformed or semantically drifting Greek generated by the local 4B model,
2. macOS Greek TTS spelling `βγω` as individual letters,
3. direct execution of the benchmark failing because the repo root was not on
   Python's import path.

The deterministic scenario engine remains authoritative. If a generated reply
fails the quality gate, the live station automatically uses the deterministic
canonical reply.

The TTS pronunciation mapping only changes the hidden text passed to macOS
`say`; it does not alter the transcript displayed to the visitor.
